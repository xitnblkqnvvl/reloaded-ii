## Overview

Reloaded-II is a universal mod loader and management framework for PC games, originally built for Sonic games but expanded to support any title. It provides dependency resolution between mods, a virtual filesystem for conflict-free mod layering, live mod enable/disable without restarting the game, and NuGet-powered mod distribution.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Reloaded-II** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Universal Loader** | Works with any PC game via configurable executable targeting |
| **Dependency Graph** | Automatic dependency resolution between mods at load time |
| **Live Toggle** | Enable and disable mods without restarting the game via hotkey |
| **NuGet Distribution** | Mods distributed and updated via NuGet package infrastructure |
